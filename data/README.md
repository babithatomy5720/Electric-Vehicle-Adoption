# Dataset

The original EV registration dataset is not included in this repository because of its large file size.

A representative sample (`sample_ev_data.csv`) is provided for demonstration and testing purposes.

## Dataset Processing

The project follows the following data pipeline:

Raw EV Registration Data
        ↓
Data Profiling
        ↓
Data Cleaning
        ↓
Exploratory Data Analysis
        ↓
Feature Engineering
        ↓
Model-Ready Dataset
        ↓
Machine Learning Model

## Original Dataset

The complete dataset can be obtained from the original public EV registration data source.

The sample dataset contains a subset of the original records and is intended only for demonstrating the structure and preprocessing workflow.

## Important Features

The dataset contains information such as:

- County
- City
- Make
- Model
- Electric Vehicle Type
- Electric Range
- Vehicle Location
- Registration information
- CAFV eligibility

## Note

The processed datasets generated during the project are not stored in this repository because they are large intermediate files. They can be reproduced by running the preprocessing and feature engineering notebooks.
